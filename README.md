# Tournament Platform

Оновлена платформа з обов'язковою реєстрацією/авторизацією, профілями та керуванням ролями через адміна.

## Реалізовано

- Реєстрація/логін користувачів, сесії.
- Усі нові користувачі мають роль `visitor`.
- Обов'язкове заповнення профілю після першого входу (ПІБ, email, школа, контакт).
- Адмін може призначати ролі через профіль користувача (`visitor/participant/jury/admin`).
- Створення турніру разом із першим завданням (раундом).
- Реєстрація команд капітаном:
  - введення email членів;
  - якщо email існує — користувач додається у команду;
  - якщо email відсутній — створюється новий користувач за email+ПІБ;
  - всім учасникам виставляється роль `participant`.
- Сабміти до дедлайну, оцінювання журі, leaderboard.
- Додатковий функціонал:
  - внутрішні нотифікації;
  - "live" endpoint для автооновлення leaderboard;
  - експорт leaderboard у CSV;
  - генерація сертифікатів (текстовий файл);
  - розклад турніру (події);
  - архів завершених турнірів;
  - оголошення.

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```
