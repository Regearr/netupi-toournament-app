# Tournament Platform (MVP)

Повнофункціональна базова платформа для командного турніру з ролями **Admin / Team / Jury**.

## Що реалізовано

- Ролі користувачів + сидер демо-користувачів.
- Створення турнірів зі статусами та вікном реєстрації.
- Реєстрація команд з валідаціями email/дублів/лімітів.
- Створення раунду із вимогами, must-have, дедлайном.
- Подача/редагування сабміту до дедлайну.
- Рандомний розподіл сабмітів між журі (мінімум K оцінок на роботу).
- Інтерфейс журі для виставлення балів 0-100 по категоріях.
- Формування leaderboard (середній бал команди).
- Базовий профіль користувача по ролях.

## Архітектура

- `FastAPI` + `SQLAlchemy` + `SQLite`
- `Jinja2` шаблони для UI

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Відкрити: `http://127.0.0.1:8000`.

## Тести

```bash
pytest -q
```

## Короткий сценарій демо

1. POST `/users/seed` — створити admin/jury.
2. Через UI створити турнір.
3. Зареєструвати команду.
4. Створити раунд.
5. Додати сабміт.
6. Запустити assign evaluations.
7. Відкрити `/jury/{id}` та виставити оцінки.
8. Перевірити leaderboard на сторінці турніру.
